# Paper — `Internship/paper/`

LaTeX (IEEEtran) source for the write-up of the **Internship pipeline**: a
migration of an earlier fixed-snapshot 2016 Airbnb-demand-forecasting study to
the open, continuously-updated Inside Airbnb data for New York City
(July 2025 -- March 2026). The modelling philosophy (leakage-safe pipelines,
tree ensembles, a convex weighted blend) carries over from the original study;
every feature, target, and result here is re-derived from the new dataset
under a strict rule that no feature may be built from 2026 information.

Two manuscript variants live side by side:

| File | Description |
|---|---|
| `main.tex` | Named-author version (Bakır & Başkal), general/independent-report framing — no course/institution scope statements, no Kaggle leaderboard section. |
| `main_journal.tex` | Double-blind, anonymized journal version — passive/impersonal voice, adds a Held-Out Test Performance subsection, a Failure-Case Analysis with real worst-residual listings, and a combined Ablation Study + Migration Notes section. |
| `references.bib` | Shared bibliography (includes an Inside Airbnb data-source entry and LightGBM/CatBoost citations). |

Both variants report the same underlying numbers, pulled directly from
`../outputs/` (5-fold CV results, blend weights, significance test, residual
bins, hurdle-model results) and `../notebooks/02_FeatureEngineering.ipynb`
(feature inventory, target construction, EDA stats). If the pipeline is
re-run and the numbers in `../outputs/` change, the tables in both `.tex`
files need to be updated by hand — there is currently no automated
number-injection step for this revision (see "New analysis is reproducible"
below for what *is* automated).

## Deliverables

The existing `Final_Project_Paper_Bakir_Baskal_IEEE*.docx/.pdf` and
`_ieee_base.docx` / `_journal_base.docx` files in this folder are build
artifacts of the **original 2016-data paper** and are now stale relative to
`main.tex`/`main_journal.tex`. They are kept for reference but should be
regenerated (see below) before being treated as current deliverables.

## How to build

### A. Word + PDF — no LaTeX needed
The two-column Word/PDF are produced from a `.tex` source with a three-step
pandoc pipeline (needs `pypandoc_binary`, `docx2pdf`, `python-docx`,
`pymupdf`, and Microsoft Word installed for the PDF step). Substitute
`main.tex`/`build_ieee_docx.py` for the named-author IEEE variant, or
`main_journal.tex`/`build_journal.py` for the double-blind journal variant:
```
# 1. LaTeX -> Word (equations + figures + IEEE-numbered refs)
python -c "import pypandoc; pypandoc.convert_file('main.tex','docx',outputfile='_ieee_base.docx',extra_args=['--citeproc','--bibliography=references.bib','--csl=ieee.csl','--resource-path=.;figures'])"
# 2. impose IEEE two-column layout (Times, margins, headings, section break)
python build_ieee_docx.py
# 3. Word -> PDF
python -c "from docx2pdf import convert; convert('Final_Project_Paper_Bakir_Baskal_IEEE.docx','Final_Project_Paper_Bakir_Baskal_IEEE.pdf')"
```
`ieee.csl` gives the numbered `[1]` citation style.

### B. Pure LaTeX (Overleaf) — most authentic IEEE typesetting
Zip the whole `paper/` folder (including `figures/`), upload to Overleaf, set
the main file to `main.tex` (or `main_journal.tex`), press *Recompile*. Or
locally with MiKTeX / TeX Live:
```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## What changed in the migration to Inside Airbnb 2025-2026

Both `.tex` files were rewritten section-by-section against the actual
Internship pipeline outputs: dataset/EDA (36,261 listings, clean multi-snapshot
target, H2-2025-only feature window), feature engineering (206 columns,
cross-snapshot calendar-volatility as the strongest predictor), model roster
(9 configurations incl. LightGBM/CatBoost and 3 XGBoost variants), an
incremental ablation, a real significance test and residual analysis, an
**implemented** (not just proposed) two-stage hurdle model, and updated
appendices (feature inventory, reproducibility/execution environment). The
Kaggle-competition framing, COMP468 course scope statements, and leaderboard
appendix from the original study were removed; `main.tex` keeps both original
authors but describes only the Internship pipeline's own work, and
`main_journal.tex` keeps its double-blind anonymization throughout.

## New analysis is reproducible
The significance numbers and the two residual figures can be recomputed from
the saved OOF predictions in `../outputs/` via
`../notebooks/12_Residuals_and_Significance.ipynb`. Re-running that notebook
regenerates `outputs/residual_analysis.png`, `outputs/residuals_by_truebin.png`,
and `outputs/significance_report.txt` (copied into `paper/figures/` as
Fig. 6–7).

## Notes
- The figures in `figures/` (`fig1`–`fig7`) are generated by
  `../notebooks/14_figures.ipynb` from the Internship pipeline's own outputs —
  they already reflect the new dataset and did not need to change when the
  `.tex` prose was rewritten.
- A real `5x2cv` paired t-test (Dietterich, 1998) would require re-running the
  whole pipeline over 5 two-fold splits; both papers note this and report the
  sample-level paired test that the compute budget allowed.
- `fix_table2.py` and `fix_voice.py` are one-off patch scripts from the
  original 2016-data paper's docx post-processing; they are not part of the
  regular rebuild path for the current `.tex` sources.
